# Aegis Palworld Suite v2.3.0

## Highlights

- Native Windows launcher
- Searchable Palworld item database
- Admin command generation
- Clipboard integration
- Paldeck database update workflow
- Custom Aegis branding
- Improved startup logging and path handling

## Installation

1. Download `Aegis-Palworld-Suite-2.3.0.zip`.
2. Extract the entire archive.
3. Run `Launcher.exe`.

Keep all included folders beside `Launcher.exe`.
